# 当季买什么

面向买菜新手的免费 Web 工具。手机优先，以暖白、深绿和食材照片呈现时令知识。视觉参考 VoltAgent/awesome-design-md 中的 Starbucks DESIGN.md，中文与信息结构为本项目重新适配。

## 运行

可先直接打开本目录的 `preview.html`，内容和图片已内嵌。该单文件完成了结构及脚本检查；自动化浏览器的协议策略禁止打开 file://，因此未验证直接打开的实际效果。HTTP 版本的主要流程已通过浏览器验证，真实定位尚未验证。

无需安装依赖。在本文件所在目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173 。请通过 HTTP 服务器访问；直接双击 HTML 会被浏览器的本地文件安全限制阻止读取 JSON。

## 检查

```sh
node check.mjs
node --check dist/app.mjs
```

修改网站内容或样式后，运行 `python3 build-offline.py` 重新生成单文件预览。

## 内容与维护

- `dist/produce.json`：40种蔬果的月份、产区、风味、挑选、保存和资料来源。
- `dist/photos.json`：图片作者、许可、来源与处理说明。图片位于 `dist/assets/`，请保留署名。
- `dist/cities.json`：用于设备内近似匹配城市的离线坐标，不能代表行政边界或用户所在区县。
- 修改内容后重新运行检查。公开的农业及科普资料均改写成简短参考，未复制整篇原文或图表；公开可访问不代表获得原图转载许可。

当季是常见产区的宽泛月份参考，受天气、品种和种植方式影响。首版没有城市专属供应数据。手选城市会说明这一限制，不改变通用产季；城市资料覆盖充分后再加入地区差异。

定位只在用户点击时调用浏览器权限，匹配在设备上完成。只保存城市名称，不上传、记录或持久化经纬度。城市位置近似匹配后需要用户确认。浏览器的定位服务自身遵循浏览器供应商策略。

## 部署

将 `dist/` 作为静态网站根目录即可，无服务端和运行时依赖。定位功能需要 HTTPS 或浏览器认可的本机安全来源。内容使用相对路径，支持静态子目录部署。

## 第三方资产

食材图片的逐张作者与许可见网页“图片署名”和 `dist/photos.json`。图片经缩放及 JPEG 压缩，在卡片中可能被裁切。CC BY-SA 图像沿用各自许可。

城市坐标整理自 [88250/city-geo](https://github.com/88250/city-geo)，按其木兰宽松许可证第2版提供；许可证副本为 `dist/licenses/city-geo-LICENSE.txt`。数据仅用于城市中心的粗略匹配。

设计文档参考：[Starbucks DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/starbucks/DESIGN.md)。采用本项目的原创标志和系统中文字体。
