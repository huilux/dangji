# 当季买什么

面向买菜新手的免费 Web 工具。手机优先，以暖白、深绿和食材照片呈现时令知识。视觉参考 VoltAgent/awesome-design-md 中的 Starbucks DESIGN.md，中文与信息结构为本项目重新适配。

## 运行

可先直接打开本目录的 `preview.html`，内容和图片已内嵌。该单文件完成了结构及脚本检查；自动化浏览器的协议策略禁止打开 file://，因此未验证直接打开的实际效果。HTTP 版本的主要流程已通过浏览器验证，真实定位尚未验证。

无需安装依赖。在本文件所在目录运行：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173 。请通过 HTTP 服务器访问；直接双击 HTML 会被浏览器的本地文件安全限制阻止读取 JSON。

## 检查

```sh
node check.mjs
node --check dist/app.mjs
```

修改网站内容或样式后，运行 `python3 build-offline.py` 重新生成单文件预览。

## 内容与维护

- `dist/produce.json`：100种食材（40种水果、60种蔬菜及食用菌菇、辛香料）的月份、产区、风味、挑选、保存、常用别名和资料来源。
- `dist/photos.json`：图片作者、许可、来源与处理说明。图片位于 `dist/assets/`，请保留署名。
- `dist/cities.json`：用于设备内近似匹配城市的离线坐标，不能代表行政边界或用户所在区县。
- 修改内容后重新运行检查。公开的农业及科普资料均改写成简短参考，未复制整篇原文或图表；公开可访问不代表获得原图转载许可。新增60种的产区、月份与指南依据及局限见 [CONTENT-SOURCES.md](CONTENT-SOURCES.md)，最近验证见 [VERIFICATION.md](VERIFICATION.md)。

当季是常见产区的宽泛月份参考，受天气、品种和种植方式影响。首版没有城市专属供应数据。手选城市会说明这一限制，不改变通用产季；城市资料覆盖充分后再加入地区差异。

定位只在用户点击时调用浏览器权限，匹配在设备上完成。只保存城市名称，不上传、记录或持久化经纬度。城市位置近似匹配后需要用户确认。浏览器的定位服务自身遵循浏览器供应商策略。

## 部署

将 `dist/` 作为静态网站根目录即可，无服务端和运行时依赖。定位功能需要 HTTPS 或浏览器认可的本机安全来源。内容使用相对路径，支持静态子目录部署。

GitHub 仓库：[huilux/dangji](https://github.com/huilux/dangji)。网站地址：[当季买什么](https://huilux.github.io/dangji/)。

`.github/workflows/pages.yml` 在推送 `main` 或手动运行时执行内容和语法检查，通过后仅上传 `dist/` 到 GitHub Pages。仓库的 Settings → Pages → Source 需选择 GitHub Actions；Actions 使用仓库自带的短期令牌，不需要额外配置密钥。首次发布等待对应工作流成功；后续直接提交并推送更新即可。

免费 Pages 使用公开仓库。国内网络访问效果需实测，不能保证不同运营商都能稳定访问。

## 第三方资产

食材图片的逐张作者与许可见网页“图片署名”和 `dist/photos.json`。图片经缩放及 JPEG 压缩，在卡片中可能被裁切。CC BY-SA 图像沿用各自许可。

城市坐标整理自 [88250/city-geo](https://github.com/88250/city-geo)，按其木兰宽松许可证第2版提供；许可证副本为 `dist/licenses/city-geo-LICENSE.txt`。数据仅用于城市中心的粗略匹配。

设计文档参考：[Starbucks DESIGN.md](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/starbucks/DESIGN.md)。采用本项目的原创标志和系统中文字体。

## Git 与这一轮 UI 优化

本目录已初始化为本地 Git 仓库，主分支为 `main`，原始版本基线为 `9b5da72`。远程仓库为 `huilux/dangji`；生成的 `preview.html` 不入库，可以从源文件重新生成。

手机清单采用单列横向卡片，名称、产季和详情入口保持可读；月份按需展开，分类和搜索工具栏随滚动保留。搜索覆盖全部月份，所选月份继续用于产季提示；搜索、分类和月份会保留在 URL，刷新后恢复。

蔬菜提供叶菜花菜、根茎、瓜果、鲜豆玉米、菌菇、葱姜蒜香料六种细分类，二级筛选可横向滑动，也可用键盘逐项选择。切换月份、分类或浏览模式会记录浏览历史；搜索输入更新当前记录，避免逐字生成历史。筛选后显示结果起点，详情返回保留清单位置，浏览器后退/前进同步恢复筛选和弹窗。直接打开详情链接时，“返回清单”会留在本站清单。

搜索有其他分类匹配时，空结果页提供“在全部蔬果中搜索”，保留关键词；没有匹配时可清除搜索。指南、城市选择、图片署名都采用顶部固定关闭入口，浏览器返回和 Escape 也能关闭。

食材资料、图片索引和城市资料分别加载。核心文字先显示，辅助资料到达后补齐，不重建已打开的详情。请求超过12秒会结束等待；核心资料失败可重新载入，图片资料失败保留名称占位，城市资料失败仍可手动输入。

详情按“食材概览 → 参考产季与月份日历 → 常见产区 → 挑选与保存 → 资料出处”排列。产季、产区和适用范围默认显示，只有出处按需展开。手机详情占满可用屏幕，返回按钮随滚动保留，并为设备安全区预留空间；输入框字号为16px。实际浏览器已检查320/390px窄屏和768/1440px大屏，尚需在真实手机Safari及Android浏览器中确认键盘、刘海和底部手势区体验。
